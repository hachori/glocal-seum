# 글로컬 세움 일반화 자료실

대전 서부 다문화교육 클러스터(중심학교 대전자운초, 협력학교 대덕초·대전전민초)의 2026 다문화교육 정책연구학교 **글로컬 세움** 일반화 자료를 모아 둔 웹사이트입니다. 운영보고서 '일반화 자료 현황' 표의 QR 12개가 이 사이트의 프로그램 화면 12개(`p01/` ~ `p12/`)로 연결됩니다.

- 빌드 과정이 없는 정적 사이트입니다(HTML·CSS·JS). GitHub Pages나 Vercel에 그대로 올리면 됩니다.
- 휴대폰 화면을 먼저 생각해서 만들었습니다(QR은 휴대폰으로 찍기 때문).

## 폴더 구조

```
index.html                 홈(영역별 자료·전체 자료·추천 영상·QR 안내·연구학교 운영)
p01/ ~ p12/index.html      프로그램 화면 = QR 도착 화면 (tools/build_pages.py로 만듦)
404.html                   없는 주소로 들어왔을 때
assets/data/materials.json ★ 자료 목록: 링크·소개·대상 학년 등은 여기만 고치면 됨
assets/css/site.css        디자인(색·글꼴·휴대폰 화면 규칙·움직임 효과)
assets/js/app.js           materials.json을 읽어 화면을 채우는 코드
assets/fonts/              에이투지체 웹 글꼴(굵기 400~800)
assets/img/                로고·영역 로고·파비콘
tools/                     프로그램 화면 생성기, 글꼴 줄이기 스크립트
```

## 자료 링크 넣기 (materials.json)

`assets/data/materials.json`의 `programs` 안에 프로그램 12개가 QR 번호 순서대로 있습니다. 자료마다 `url`만 채우면 화면의 '준비 중'이 [보기]·[받기]·[열기] 버튼으로 바뀝니다.

```json
{ "title": "3교 15개국 인사말 자료", "type": "doc", "url": "https://drive.google.com/file/d/…/view", "note": "PDF" }
```

| 칸 | 내용 |
|---|---|
| `type` | `video`(영상) · `doc`(문서) · `tool`(웹 도구) |
| `url` | 비워 두면 '준비 중'. 영상은 유튜브 주소(재생목록 `list=` 주소도 됨), 문서는 구글 드라이브 '링크가 있는 모든 사용자' 공유 주소 |
| `note` | 형태 옆에 붙는 짧은 설명(예: `PDF · 2.1MB`, `재생목록`). 비우면 기본 문구 |

프로그램마다 `summary`(한 줄 소개), `target`(대상 학년), `school`(제작 학교), `date`(탑재일)를 채우면 프로그램 화면에 나타납니다. 비어 있으면 그 줄은 보이지 않습니다.

- 드라이브 파일을 고칠 때는 **'버전 관리 → 새 버전 업로드'**를 쓰면 링크가 그대로 유지됩니다.
- 유튜브 영상은 프로그램 화면 안에서 바로 재생됩니다(누르기 전에는 썸네일만 불러와 휴대폰 데이터를 아낍니다).
- 프로그램 이름·영역을 바꾸었다면 `python tools/build_pages.py`를 한 번 실행해 p01~p12의 제목을 다시 만듭니다.

## 내 컴퓨터에서 미리 보기

자료 목록을 파일에서 읽어 오기 때문에, `index.html`을 더블클릭으로 열면 목록이 보이지 않습니다. 이 폴더에서 다음을 실행한 뒤 브라우저로 `http://localhost:8137`을 엽니다.

```bash
python -m http.server 8137
```

## 배포와 QR 주소

- **GitHub Pages**: 저장소 Settings → Pages → Branch `main` / `(root)`. 주소는 `https://아이디.github.io/glocal-seum/`. 무료 계정은 저장소가 공개여야 합니다.
- **Vercel**: 저장소를 가져오기(Import)만 하면 됩니다(빌드 설정 없음). 주소는 `https://프로젝트이름.vercel.app/`.
- 모든 링크가 상대 주소라 어느 쪽이든 그대로 동작합니다.
- **QR 주소 규칙**: `사이트주소/p01/` ~ `사이트주소/p12/`. 끝에 `?qr`을 붙이면(`…/p01/?qr`) 화면 위에 "운영보고서 QR 01로 열린 화면입니다" 알림이 잠깐 뜹니다. 주소는 42자 이하로 두면 지금 보고서의 QR 크기(버전 3)에 그대로 들어갑니다.
